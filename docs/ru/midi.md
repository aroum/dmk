# Поддержка MIDI

Прошивка поддерживает отправку MIDI-сообщений (ноты, изменение параметров CC, Pitch Bend, управление октавой, каналом и транспонированием) напрямую с клавиш и энкодеров.

## Сборка и настройка MIDI

Поддержка MIDI гибко настраивается в файле `config.h` клавиатуры с помощью следующих определений:

- `#define MIDI_USB`: Включает поддержку USB MIDI (через TinyUSB на RP2040 или аппаратный USB-драйвер на Milandr).
- `#define MIDI_JACK`: Включает поддержку физического MIDI-порта (DIN-5) через UART.
- `#define MIDI_THRU`: При включенном `MIDI_JACK` дублирует входящий поток с MIDI-входа напрямую на MIDI-выход.

### Определение пинов для физического MIDI-порта

Если включен дефайн `MIDI_JACK`, необходимо также указать пины для подключения UART:

```c
#define PIN_MIDI_JACK_OUT 0 // Номер пина для отправки (TX)
#define PIN_MIDI_JACK_IN 1  // Номер пина для приема (RX)
```

Пример команды сборки:

```bash
./build_all.sh --keyboard omsk --mcu rp2040 -cs -d MIDI_USB -d MIDI_JACK
```

Если ни одно из определений `MIDI_USB` или `MIDI_JACK` не указано, вся поддержка MIDI полностью вырезается из прошивки для экономии флеш-памяти.

### Назначение фиксированных значений MIDI CC на клавиши

В статической раскладке в `config.h` вы можете назначить клавише отправку конкретного значения MIDI CC при нажатии с помощью макроса `MIDI_CC(cc, value)`:

- **Нажатие клавиши**: Отправляет MIDI CC сообщение с номером `cc` (0–127) и значением `value` (0–127).
- **Отпускание клавиши**: Отправляет MIDI CC сообщение с номером `cc` и значением `0`.

Также доступны специализированные макросы ручного маппинга:

- `MIDI_CC_X_VAL_127(cc)`: Отправляет значение 127 при нажатии, и 0 при отпускании CC с номером `cc`.
- `MIDI_CC_X_TOGGLE(cc)`: Переключает состояние CC с номером `cc` между 127 и 0 при каждом нажатии.

Пример использования в раскладке:

```c
MIDI_CC(10, 127),     // Отправит CC 10 со значением 127 при нажатии, и 0 при отпускании
MIDI_CC_X_VAL_127(11), // То же самое для CC 11
MIDI_CC_X_TOGGLE(12),  // Будет переключать состояние CC 12 (127 -> 0 -> 127) при нажатии
```

Поддерживаются стандартные кейкоды MIDI (соответствующие QMK MIDI):

- **Ноты**: от `MIDI_NOTE_C_0` до `MIDI_NOTE_B_5` (6 октав нот, динамически транспонируемых настройками октавы/транспонирования).
- **Управление октавой**: `MIDI_OCTAVE_DOWN` / `MIDI_OCTAVE_UP` и прямой выбор октавы (`MIDI_OCTAVE_N2` .. `7`).
- **Транспонирование**: `MIDI_TRANSPOSE_DOWN` / `MIDI_TRANSPOSE_UP` и прямой выбор транспозиции.
- **Громкость/Велосити**: `MIDI_VELOCITY_DOWN` / `MIDI_VELOCITY_UP` и прямой выбор силы нажатия (`0` .. `10`).
- **MIDI Канал**: `MIDI_CHANNEL_DOWN` / `MIDI_CHANNEL_UP` и прямой выбор канала (`1` .. `16`).
- **Дополнительно**:
  - `MIDI_ALL_NOTES_OFF`: Паника, выключает все звучащие ноты.
  - `MIDI_SUSTAIN` / `MIDI_PORTAMENTO` / `MIDI_SOSTENUTO` / `MIDI_SOFT` / `MIDI_LEGATO`: Стандартные педали и CC-эффекты.
  - `MIDI_PITCH_BEND_DOWN` / `MIDI_PITCH_BEND_UP`: Симуляция колеса Pitch Bend.

## Продвинутый MIDI и интеграция с Vial

Поддержка настройки MIDI полностью интегрирована с **Vial**.

### Кастомные кейкоды MIDI CC Inc / Dec

Vial позволяет назначать на кнопки или вращение энкодеров инкремент и декремент абсолютных значений параметров MIDI Control Change (CC):

- **MIDI CC 0-15 Inc**: `MIDI_CC_X_INC` (значения `0x7E00` – `0x7E0F`)
- **MIDI CC 0-15 Dec**: `MIDI_CC_X_DEC` (значения `0x7E10` – `0x7E1F`)
- **MIDI CC 0-15 Val 127**: `MIDI_CC_X_VAL_127` (значения `0x7E20` – `0x7E2F`)
- **MIDI CC 0-15 Toggle**: `MIDI_CC_X_TOGGLE` (значения `0x7E30` – `0x7E3F`)

Они доступны на вкладке **Custom** в интерфейсе Vial.

### Настройка энкодеров (Абсолютный режим CC)

Чтобы настроить энкодер на управление значением CC (например, громкостью/CC 10) в абсолютном режиме:

1. Назначьте **вращение по часовой стрелке (CW)** на `MIDI CC 10 Inc`.
2. Назначьте **вращение против часовой стрелки (CCW)** на `MIDI CC 10 Dec`.

При вращении энкодер будет увеличивать или уменьшать значение CC 10 (от 0 до 127, по умолчанию 64) и отправлять в компьютер точное абсолютное значение.

| **Транспонирование**         | `MIDI_TRANSPOSE_N6` .. `MIDI_TRANSPOSE_6`                                           | от -6 до 6 полутонов      | Сдвигает строй клавиатуры                                     |
| **Сдвиг транспозиции**       | `MIDI_TRANSPOSE_DOWN` / `MIDI_TRANSPOSE_UP`                                         | —                         | Понижает или повышает транспозицию на полутон                 |

| **Статический CC (клавиша)** | `MIDI_CC(cc, value)`                                                                | cc: 0..127, value: 0..127 | При нажатии отправляет `value`, при отпускании отправляет `0` |
