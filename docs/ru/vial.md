# Руководство по интеграции Vial / VIA

Vial — это кроссплатформенное приложение с открытым исходным кодом для настройки раскладок клавиатуры, макросов и параметров в режиме реального времени. В этом руководстве объясняется, как собрать и настроить `dmk-firmware` с поддержкой Vial.

---

## 🛠️ Включение поддержки Vial

Поддержку Vial можно включить двумя способами:

1. **Через файл конфигурации клавиатуры**: Добавьте директиву `#define VIAL` в файл `config.h` вашей клавиатуры (например, в [keyboards/corne/config.h](file:///home/aroum/Documents/dmk-firmware/keyboards/corne/config.h)). Это предпочтительный способ, так как он сохраняется непосредственно в исходном коде вашей раскладки.
2. **Через параметр сборки CMake**: Передайте флаг `-DVIAL=ON` при конфигурации сборки.

Когда поддержка Vial активна, компилируется C-модуль обработки команд и инициализируется второй USB-интерфейс **Raw HID** для обмена данными между клавиатурой и графическим интерфейсом Vial.

### Примеры команд для сборки

- **Сборка с использованием настроек в `config.h`** (если задано `#define VIAL`):
  ```bash
  ./build_all.sh -b corne --mcu rp2040 -c --uf2
  ```
- **Сборка с явной передачей флага CMake**:
  ```bash
  cmake -DVIAL=ON -DKEYBOARD=corne -DMCU=rp2040 build && cmake --build build
  ```

## 🗺️ Как это работает

1. **Определение раскладки Vial (`vial.json`)**:
   Каждая клавиатура, поддерживающая Vial, должна определить свои физические раскладки, идентификатор производителя (Vendor ID) и продукта (Product ID) в файле `vial.json` внутри каталога клавиатуры (например, `keyboards/corne/vial.json`).

2. **Автоматическое сжатие**:
   Система сборки CMake автоматически вызывает скрипт Python (`tools/vial/compress.py`) для сжатия `vial.json` с помощью алгоритма LZMA (формат контейнера `FORMAT_ALONE`). При этом в каталоге клавиатуры создается заголовочный файл C `vial_generated.h`, содержащий:
   - `vial_keyboard_def[]`: Сжатый массив определения раскладки.
   - `vial_keyboard_id[]`: Уникальный 8-байтовый идентификатор, полученный путем хеширования файла раскладки.

3. **Динамическая раскладка и энергонезависимая память (EEPROM)**:
   При запуске прошивка загружает сохраненные конфигурации из памяти EEPROM, если они есть.
   - Логика сканирования клавиш считывает данные из динамического массива.
   - Vial позволяет редактировать любые коды клавиш «на лету».
   - Изменения конфигурации (раскладка, макросы и настройки RGB) сохраняются в EEPROM (в настоящее время поддерживается на контроллерах Миландр) при отправке команды сохранения из интерфейса Vial.

## 💡 Интеграция с RGB-подсветкой

`dmk-firmware` поддерживает управление WS2812 RGB-подсветкой напрямую через интерфейс Vial:

- **Поддерживаемые контроллеры**: RP2040 (через PIO) и nRF52840 (через SPIM).
- **Возможности**: Включение/выключение подсветки, настройка яркости, выбор статического цвета (Hue и Saturation), сохранение и загрузка настроек в/из EEPROM.
- **Настройка RGB**:
- Укажите `RGB_NUM` (количество светодиодов) и `RGB_PIN` в конфигурационном файле `config.h` вашей клавиатуры (например, в [keyboards/pncateho/config.h](file:///Users/aroum/Documents/GitHub/dmk-firmware/keyboards/pncateho/config.h)).
- Опционально: Определите макрос `RGB_MAP` для переопределения соответствия логических индексов светодиодов их физическому расположению.

### 🎭 Поддерживаемые RGB-эффекты

Хотя в интерфейсе Vial отображается полный список анимаций QMK, в `dmk-firmware` реализован оптимизированный набор эффектов для экономии памяти микроконтроллера. Поддерживается только первый индекс каждого типа анимации:

1. **Solid Color (Статический цвет)** (`RGBLIGHT_MODE_STATIC_LIGHT`)
2. **Breathing 1 (Дыхание 1)** (`RGBLIGHT_MODE_BREATHING`)
3. **Rainbow Mood 1 (Радужное настроение 1)** (`RGBLIGHT_MODE_RAINBOW_MOOD`)
4. **Rainbow Swirl 1 (Радужный вихрь 1)** (`RGBLIGHT_MODE_RAINBOW_SWIRL`)
5. **Snake 1 (Змейка 1)** (`RGBLIGHT_MODE_SNAKE`)
6. **Knight 1 (Рыцарь 1 / Бегущий огонь)** (`RGBLIGHT_MODE_KNIGHT`)
7. **Christmas (Рождество)** (`RGBLIGHT_MODE_CHRISTMAS`)
8. **Gradient 1 (Градиент 1)** (`RGBLIGHT_MODE_STATIC_GRADIENT`)

> [!NOTE]
> Другие вариации, отображаемые в Vial (такие как _Breathing 2–4_, _Rainbow Mood 2–3_, _Rainbow Swirl 2–6_, _Snake 2–6_, _Knight 2–3_, _Gradient 2–10_, _RGB Test_ и _Alternating_), **не реализованы** и работать не будут (эффект будет статичным или выключенным).

## 📊 Таблица поддерживаемых функций Vial в dmk-firmware

Ниже приведено текущее состояние реализации возможностей Vial / VIA в `dmk-firmware`:

| Функция Vial / VIA                          | Состояние в dmk-firmware | Описание / Ограничения                                                                                                      |
| ------------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| **Динамическая раскладка (Dynamic Keymap)** | 🟢 Поддерживается        | Изменяется «на лету» в реальном времени. На платах Milandr изменения сохраняются в энергонезависимую память (EEPROM).       |
| **Количество слоев (Layers)**               | 🟢 Поддерживается        | Поддерживается до 16 независимых слоев.                                                                                     |
| **Тестировщик клавиш (Matrix Tester)**      | 🟢 Поддерживается        | Работает через стандартный протокол VIA/Vial без ограничений.                                                               |
| **Управление RGB (RGB Lighting)**           | 🟢 Поддерживается        | Поддерживается включение, яркость, скорость анимации и 8 стандартных QMK-эффектов/анимаций.                                 |
| **Безопасность (Unlock/Lock)**              | 🟡 Упрощено              | Блокировка раскладки обойдена (устройство всегда разблокировано для удобства настройки).                                    |
| **Макросы (Macros)**                        | 🟢 Поддерживается        | Поддерживается динамическая запись макросов (до 16 макросов, буфер 2048 байт) через графический интерфейс Vial.             |
| **Энкодеры (Encoders)**                     | ❌ Не поддерживается     | Заглушено в протоколе. Физические энкодеры не обрабатываются Vial.                                                          |
| **Tap Dance**                               | ❌ Не поддерживается     | Динамическая настройка Tap Dance через интерфейс Vial отключена.                                                            |
| **Комбо (Combos)**                          | 🟢 Поддерживается        | Поддерживается динамическая настройка Combo (аккордов) (до 8 комбо, до 4 клавиш в каждом) через графический интерфейс Vial. |
| **Переопределение клавиш (Key Overrides)**  | ❌ Не поддерживается     | Функция недоступна.                                                                                                         |

---

## 🔒 Безопасность и Тестировщик Матрицы

Для данной реализации функции блокировки Vial (Vial lock) обходятся (устройство всегда разблокировано для простоты). Изменения раскладки и настройки подсветки сохраняются в энергонезависимую память EEPROM на поддерживаемых MCU и сохраняются при перезагрузке.

---

## 🧪 Тестирование

1. Подключите клавиатуру к компьютеру.
2. Перейдите на страницу [Vial Web Client](https://vial.rocks/) или скачайте настольное приложение.
3. Нажмите кнопку "Start Vial" и выберите обнаруженную клавиатуру.
4. Измените любую клавишу или настройте подсветку в интерфейсе приложения и убедитесь, что изменения немедленно применились к вашей клавиатуре!
