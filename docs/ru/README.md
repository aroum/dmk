# Документация DMK Firmware

Добро пожаловать в документацию по прошивке **DMK** (Dmitry's Mechanical Keyboard firmware).

🌐 **Язык / Language:** [Русский](README.md) | [English](../en/README.md)

---

## Разделы документации

1. ⚙️ **[Конфигурация (`config.h`)](config.md)**\
   Настройка клавиатуры, USB VID/PID, кроссплатформенная конфигурация для RP2040, RP2350, Миландр, nRF52840, Байкал, параметры подсветки RGB, энкодеров и индикаторов.

2. 🔌 **[Пины и порты (`pins.md`)](pins.md)**\
   Правила указания пинов, форматы именования портов для всех поддерживаемых микроконтроллеров, матричное и прямое подключение.

3. ⌨️ **[Коды клавиш (`keycodes.md`)](keycodes.md)**\
   Полный справочник кодов клавиш: базовые символы, модификаторы, системные клавиши, мультимедиа и расширенные функции.

4. 🗺️ **[Раскладка и слои (`keymap.md`)](keymap.md)**\
   Управление слоями (MO, TO, TG, TT, OSL), переключение слоев, макросы, аккорды (Chords / Combos) и Tap Dance.

5. 🎛️ **[Модули (`modules.md`)](modules.md)**\
   Поддерживаемые аппаратные модули: RGB подсветка (WS2812 / SK6812), дисплеи (OLED SSD1306, LCD ST7789), энкодеры EC11.

6. 🎹 **[MIDI (`midi.md`)](midi.md)**\
   Настройка MIDI-устройства через USB: отправка нот, контроллеров (CC), Pitch Bend и переключение каналов.

7. 🛠️ **[Сборка прошивки (`build.md`)](build.md)**\
   Инструкция по сборке прошивки через `build_all.sh` / `build_all.ps1`, локальная среда (CMake, Ninja, GCC ARM) и сборка через GitHub Actions.

8. 🔧 **[Интеграция с Vial / VIA (`vial.md`)](vial.md)**\
   Генерация `vial.json`, настройка динамической раскладки в EEPROM/Flash, разблокировка и безопасность Vial.
