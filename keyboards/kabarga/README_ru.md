# Клавиатура Kabarga

**Kabarga** — эргономичная клавиатура на базе прошивки DMK Firmware в форм-факторе контроллеров Pro Micro. Поддерживает микроконтроллеры **Baikal BE-U1000** (RISC-V), **nRF52840**, **Milandr K1986BE92FI** и **RP2040/RP2350**.

---

## Аппаратные ревизии

Существуют две аппаратные ревизии печатной платы Kabarga, отличающиеся разводкой строк матрицы и поддержкой RGB-подсветки:

| Параметр | Классическая (Standard) | Kabarga CE (Community Edition) |
| :--- | :--- | :--- |
| **Пины строк (7 строк)** | `{PM_21, PM_20, PM_19, PM_1, PM_0, PM_2, PM_3}` | `{PM_0, PM_3, PM_2, PM_21, PM_20, PM_19, PM_18}` |
| **Пины колонок (6 колонок)** | `{PM_9, PM_8, PM_7, PM_6, PM_5, PM_4}` | `{PM_9, PM_8, PM_7, PM_6, PM_5, PM_4}` |
| **Пин `PM_1` (Pro Micro D1 / TX)** | Задействован под 3-ю строку матрицы | Освобождён из матрицы, выведен под **RGB-подсветку** (`RGB_PIN`) |
| **RGB-подсветка** | Отсутствует (нет отдельного пина) | **42 светодиода WS2812** на пине `PM_1` |
| **Флаг сборки** | Не требуется (по умолчанию) | **`-d CE`** (`--define CE`) |
| **Имя бинарника** | `dmk_kabarga_<mcu>` | `dmk_kabarga_<mcu>_ce` |

> [!WARNING]
> Если собрать прошивку для платы Kabarga CE **без флага `-d CE`**:
> 1. Подсистема подсветки не скомпилируется вовсе (`NO_RGB`). В Vial вкладка Lighting будет показывать «All Off», яркость 0, и включить подсветку будет невозможно.
> 2. Пин `PM_1` будет сканироваться как строка матрицы, а не передавать сигнал WS2812.

## Сборка прошивки

### 1. Сборка для Kabarga CE (с подсветкой)
Обязательно передавайте флаг `-d CE`:

```bash
# Для Baikal BE-U1000:
./build_all.sh -c -b kabarga --mcu baikal -d CE

# Для nRF52840:
./build_all.sh -c -b kabarga --mcu nrf52840 -d CE

# Для RP2040:
./build_all.sh -c -b kabarga --mcu rp2040 -d CE
```

Результирующий бинарник:
- `build/dmk_kabarga_baikal_ce.uf2` (а также `.bin` / `.hex`)

### 2. Сборка для классической Kabarga
Сборка без дополнительных флагов:

```bash
./build_all.sh -c -b kabarga --mcu baikal
```

Результирующий бинарник:
- `build/dmk_kabarga_baikal.uf2`

## Прошивка (Baikal BE-U1000)

1. Переведите плату в режим загрузчика (Bootloader) двойным нажатием кнопки Reset или зажав Boot при нажатии Reset.
2. В системе смонтируется накопитель `BAIKAL_LI`.
3. Скопируйте файл прошивки:
   ```bash
   cp build/dmk_kabarga_baikal_ce.uf2 /Volumes/BAIKAL_LI/
   ```
4. Плата автоматически прошьётся, размонтирует диск и перезагрузится в рабочий режим.

## Параметры конфигурации

В файле [`keyboards/kabarga/config.h`](config.h):
* `RGB_LIMIT_VAL`: Ограничение максимальной яркости (0–255) для всех 42 светодиодов WS2812 во избежание перегрева встроенных стабилизаторов питания (по умолчанию `60`).
* `TAPPING_TERM_DEFAULT`: Длительность удержания для двухфункциональных клавиш Hold-Tap (по умолчанию `200` мс).
* `vial.json`: Разметка матрицы и визуализация раскладки для графического конфигуратора [Vial](https://get.vial.today/).
