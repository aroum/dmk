# Руководство по установке и прошивке

В этом руководстве описан процесс сборки, прошивки и первичной калибровки клавиатуры **Le Capybara** с прошивкой DMK.

> [!WARNING]
> Прошивка микроконтроллеров всегда сопряжена с определенным риском. Убедитесь в стабильности питания по шине USB во время процесса прошивки.

---

## Карта памяти и параметры прошивки

Клавиатура Le Capybara использует микроконтроллер **STM32F072C8T6** с объемом памяти Flash 128 КБ и 16 КБ SRAM.

- **Базовый адрес Flash:** `0x08000000` (смещение 0)
- **Адрес таблицы векторов:** `0x08000000`
- **Загрузчик (Bootloader):** Заводской ST System ROM DFU Bootloader (`0x1FFFC800`, USB VID:PID `0483:df11`)
- **Сектор настроек и калибровки:** Flash Page 62 (`0x0801F000`, 2 КБ для эмуляции EEPROM)

---

## Необходимые инструменты

Убедитесь, что в системе установлен тулчейн ARM и утилита прошивки:

```bash
# macOS (через Homebrew)
brew install arm-none-eabi-gcc cmake ninja dfu-util

# Debian / Ubuntu
sudo apt update
sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi cmake ninja-build dfu-util
```

### Правила udev для Linux

Если вы работаете под управлением Linux, разрешите доступ к бутлоадеру ST DFU обычным пользователям:

```bash
sudo tee /etc/udev/rules.d/50-dfu-util.rules << 'EOF'
SUBSYSTEM=="usb", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="df11", MODE="0666"
EOF
sudo udevadm control --reload-rules
sudo udevadm trigger
```

## Перевод в режим загрузчика (DFU)

Перевести клавиатуру Le Capybara в режим DFU можно двумя способами:

### 1. Аппаратный способ
- Зажмите кнопку **BOOT0** (или замкните тестовые площадки BOOT0).
- Подключите клавиатуру к компьютеру через USB-кабель (или нажмите кнопку RESET, удерживая BOOT0).
- Отпустите BOOT0.
- Проверьте обнаружение устройства в режиме DFU:
  ```bash
  dfu-util -l
  # В выводе должно отобразиться: Found DFU: [0483:df11] ver=2200, alt=0, name="@Internal Flash  /0x08000000/064*0002Kg"
  ```

### 2. Программный способ
- Если клавиатура уже прошита DMK:
  - Нажмите назначенный кейкод загрузчика (`K_BOOT` / `QK_BOOT`) на любом слое.
  - Либо воспользуйтесь кнопкой **Reset into Bootloader** в интерфейсе VIA / Vial.

## Запись прошивки

### С использованием CMake

В корневом каталоге репозитория DMK:

```bash
# Сборка прошивки
cmake -B build/le_capybara -DKEYBOARD=le_capybara
cmake --build build/le_capybara

# Автоматическая прошивка устройства
cmake --build build/le_capybara --target flash
```

### Прямой вызов `dfu-util`

Вы можете вручную вызвать утилиту `dfu-util` для созданного бинарного файла:

```bash
dfu-util -a 0 -d 0483:df11 -s 0x08000000:leave -D build/le_capybara/dmk_le_capybara_stm32f072.bin
```

Флаг `:leave` указывает микроконтроллеру выйти из режима бутлоадера и запустить только что записанную прошивку.

## Первичная калибровка клавиш

Электроемкостные переключатели (Topre) требуют точной калибровки индивидуальной базовой емкости и максимального хода конических пружин.

> [!TIP]
> После первой прошивки рекомендуется выполнить калибровку всех клавиш через интерфейс VIA. Пошаговые инструкции описаны в [Руководстве по настройке VIA](via.md#процесс-калибровки-клавиш).
