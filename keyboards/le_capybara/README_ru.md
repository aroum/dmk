# Прошивка DMK для Le Capybara

Альтернативная высокопроизводительная прошивка для электроемкостной (EC-совместимой) клавиатуры **Le Capybara** (автор проекта: sporkus). Работает на базе движка DMK и FreeRTOS под управлением микроконтроллера **STM32F072C8T6**.

**Документация:** [Установка и прошивка](docs/ru/install.md) • [VIA и настройка](docs/ru/via.md)

---

## Возможности

- **Движок электроемкостной матрицы (EC-style):**
  - Непрерывный опрос матрицы на частоте 1000 Гц.
  - Индивидуальное отслеживание базовой емкости (baseline) для каждой клавиши с компенсацией дрейфа.
  - Калибровка емкости в реальном времени с сохранением во внутреннюю Flash-память MCU (Page 62).
  - Настраиваемая точка срабатывания (Actuation Point) и гистерезис отжатия.
  - **Rapid Trigger:** динамическая чувствительность нажатия и отпускания с шагом 0.1 мм.
- **Поддержка энкодера:**
  - Аппаратное чтение квадратурного энкодера на пинах PB4 / PB5.
  - Дискретная встроенная кнопка энкодера на PB3 (`KNOB_SW`).
- **Выбор конфигурации нижнего ряда (Thumb Cluster):**
  - **Classique (по умолчанию):** 4 клавиши в блоке большого пальца.
  - **36-Key Split:** 6 клавиш в блоке большого пальца (переключается в настройках раскладки VIA).
- **Поддержка VIA и Vial:**
  - **VIA v3:** Специальное интерактивное меню настроек (Калибровка, Rapid Trigger, Монитор матрицы, Частота опроса).
  - **Vial:** Удобный графический конфигуратор без дополнительных файлов определений.
  - Легкое переключение конфигурации при сборке через флаг `-DVIAL_ENABLE=ON/OFF`.

## Аппаратные характеристики

| Компонент | Спецификация |
| :--- | :--- |
| **Микроконтроллер** | STMicroelectronics STM32F072C8T6 (ARM Cortex-M0, 48 МГц) |
| **Flash / RAM** | 128 КБ Flash / 16 КБ SRAM |
| **Тип переключателей** | Электроемкостные (EC с конической пружиной) |
| **Количество клавиш** | 37–40 клавиш (в зависимости от раскладки) + энкодер |
| **Канал АЦП** | 12-битный АЦП на PA2 |
| **Пин разряда** | PA1 (Drain / Discharge) |
| **Управление мультиплексором** | PA3, PA4, PA5 (мультиплексор 74HC4051 8:1) |
| **Стробы (Strobe)** | PB0, PB1, PB2, PB10, PB11 |
| **Энкодер** | PB4 (A), PB5 (B), PB3 (кнопка) |
| **Загрузчик** | Встроенный ST ROM DFU Bootloader (`0x1FFFC800`) |

## Быстрый старт

### 1. Сборка прошивки

#### С использованием `build_all.sh` (Linux / macOS) или `build_all.bat` / `build_all.ps1` (Windows):

```bash
# Linux / macOS (сборка с очисткой директории)
./build_all.sh -b le_capybara -c

# Windows (Командная строка / cmd.exe)
build_all.bat -b le_capybara -c

# Windows (PowerShell)
.\build_all.ps1 -Keyboard le_capybara -Clean
```

#### Напрямую через CMake:

```bash
# Сборка с поддержкой Vial (по умолчанию)
cmake -B build/le_capybara -DKEYBOARD=le_capybara
cmake --build build/le_capybara

# Сборка с интерактивными меню VIA v3
cmake -B build/le_capybara_via -DKEYBOARD=le_capybara -DVIAL_ENABLE=OFF
cmake --build build/le_capybara_via
```

### 2. Запись прошивки

Переведите клавиатуру в режим DFU (зажмите аппаратную кнопку `BOOT0` при подключении кабеля USB или нажатии Reset) и выполните:

```bash
# Прямая прошивка через dfu-util:
dfu-util -a 0 -d 0483:df11 -s 0x08000000:leave -D build/le_capybara/dmk_le_capybara_stm32f072.bin

# Либо через таргет CMake:
cmake --build build/le_capybara --target flash
```

Подробное руководство см. в [Инструкции по установке](docs/ru/install.md).

## Структура каталога

- `config.h` — геометрия матрицы, назначение пинов и конфигурация модулей.
- `capybara_matrix.c` / `capybara_matrix.h` — сканирование аналогового мультиплексора и управление пином разряда.
- `matrix.c` — задача опроса матрицы и генерация событий нажатий.
- `ec_settings.c` / `ec_settings.h` — хранение калибровок и эмуляция EEPROM во Flash.
- `rapid_trigger.c` / `rapid_trigger.h` — логика работы Rapid Trigger.
- `hhkb_via_controls.c` — обработка интерактивных команд и меню VIA.
- `via.json` — определение клавиатуры и меню настроек для VIA v3.
- `vial.json` — определение клавиатуры для Vial.
- `docs/` — руководства пользователя и документация.
