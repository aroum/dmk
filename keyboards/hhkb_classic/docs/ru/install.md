# Установка

> [!WARNING]
> Вы прошиваете клавиатуру и используете DFU/SWD на свой страх и риск. Автор не несёт ответственности за повреждение клавиатуры, потерю данных или последствия неправильного выбора образа, модели либо способа восстановления.

## Перед прошивкой

Сначала соберите образ для нужной модели. Обычная Classic использует контейнер `AHHX01`, Type-S — `AHHS01`. Перед первой прошивкой сохраните полный бэкап.

DMK занимает Flash Bank 2 (`0x08010000–0x0801FFFF`). Заводской обновитель в Bank 1 остаётся на месте и предоставляет PFU-интерфейс.

## Установка через PFU-обновитель

Если на клавиатуре сейчас работает заводская PFU-прошивка, интерфейс обновления PFU уже доступен: **не используйте SW6**. Откройте подходящий `.hfb` в HHKB Keymap Tool и выполните штатное обновление.

Если сейчас работает DMK, у неё другой USB-идентификатор, поэтому Keymap Tool не прошивает её напрямую. При выключенной клавиатуре переведите SW6 в ON, подайте питание и после запуска Bank 1 верните SW6 в OFF. Recovery стирает первую 128-байтную страницу Bank 2. Подробное описание необратимого перехода в Bank 1 — в разделе [Recovery SW6](backup-restore.md#recovery-sw6). Затем прошейте созданный `.hfb` штатным обновителем и переподключите клавиатуру после завершения.

## Установка прошивальщиком DMK

Использовать штатный Keymap Tool не обязательно. `hhkb_flasher.py` передаёт тот же `.hfb` через интерфейс обновления PFU и работает на разных ОС, в том числе на Linux, где штатного Keymap Tool нет. Заводская прошивка уже предоставляет этот интерфейс, а работающий DMK нужно сначала вернуть в Bank 1 через SW6, как описано выше.

```bash
uv run --with hidapi python3 tools/hhkb/hhkb_flasher.py --info
uv run --with hidapi python3 tools/hhkb/hhkb_flasher.py build/hhkb-script/<firmware>.hfb
```

Команда `--info` должна показать PFU-устройство нужной модели. Прошивальщик по умолчанию проверяет CRC контейнера и модель.

## DFU и SWD

ROM DFU и SWD нужны для разработки и восстановления. DFU записывает сырой `.bin` в Bank 2, но не обновляет служебные данные PFU Bank 1. Для обычной установки используйте PFU-обновитель. Пять площадок SWD рядом с разъёмом CN3 расположены в два ряда:

```text
верхний ряд:  GND | RST | VCC
нижний ряд:     CLK | DIO
```

Перед использованием этих режимов прочитайте [бэкап и восстановление](backup-restore.md).
