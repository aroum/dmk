# Бэкап и восстановление

Перед обновлением сохраните Flash, EEPROM и Option Bytes. EEPROM содержит индивидуальные заводские пороги и настройки; не переносите EEPROM между клавиатурами.

## Системный ROM DFU STM32

Системный ROM DFU STM32 — отдельный режим, не зависящий от DMK, Bank 1 или установленного образа Bank 2. Он работает без отладчика.

1. Разберите клавиатуру и снимите металлический экран с обратной стороны контроллера, чтобы получить доступ к плате.
2. При подключении USB замкните пинцетом или перемычкой **правые площадки резисторов R6 и R85**. Это поднимает BOOT0 и запускает системный загрузчик STM32. Ориентацию «правые» определяйте по фотографии, а не по произвольному положению платы; перед замыканием сверьте маркировку и площадки.
3. В исходном наблюдении индикатор загорается оранжевым. Проверьте режим по USB: STM32 DFU обычно определяется как `0483:df11`, затем уберите перемычку.

![Площадки R6 и R85 для входа в ROM DFU](https://i.imgur.com/oTwQLPg.jpeg)

Проверка устройства:

```bash
dfu-util -l
```

### Бэкап через DFU

```bash
dfu-util -a 0 -s 0x08000000:131072 -U hhkb-flash-full.bin
dfu-util -a 2 -s 0x08080000:6144 -U hhkb-eeprom.bin
dfu-util -a 1 -s 0x1FF80000:32 -U hhkb-option-bytes.bin
```

Полный дамп Flash содержит Bank 1 и Bank 2, но не EEPROM и не Option Bytes.

### Восстановление через DFU

DFU записывает сырой `.bin`, а не `.hfb`. Чтобы восстановить только Bank 2 из бэкапа **той же клавиатуры**:

```bash
dfu-util -a 0 -s 0x08010000 -D hhkb-bank2-stock-firmware_64k.bin
```

Для полного восстановления бэкапа той же платы отдельно запишите Flash и EEPROM. Option Bytes восстанавливайте только при необходимости и только из этого же бэкапа.

```bash
dfu-util -a 0 -s 0x08000000 -D hhkb-full-flash_128k.bin
dfu-util -a 2 -s 0x08080000 -D hhkb-eeprom_6k.bin
# Только при необходимости и из бэкапа этой же платы:
dfu-util -a 1 -s 0x1FF80000 -D hhkb-option-bytes.bin
```

DMK можно записать непосредственно во второй банк:

```bash
dfu-util -a 0 -s 0x08010000 -D build/hhkb/dmk_hhkb_classic_stm32l072.bin
```

ROM DFU не гарантирует обновление служебных метаданных PFU Bank 1 или флагов EEPROM. После сброса Bank 1 может отклонить образ. Для обычной установки используйте PFU-обновитель. Повторное чтение подтверждает содержимое Flash, но не принятие образа Bank 1:

```bash
dfu-util -a 0 -s 0x08010000:65536 -U bank2-readback.bin
cmp -n "$(wc -c < build/hhkb/dmk_hhkb_classic_stm32l072.bin)" \
  build/hhkb/dmk_hhkb_classic_stm32l072.bin bank2-readback.bin
```

## Полный бэкап через SWD / J-Link

Подключение SWD на плате HHKB Classic — пять площадок рядом с разъёмом CN3 в два ряда:

```text
GND  NRST  VCC
 SWCLK SWDIO
```

#### Распиновка подключения J-Link к пяти SWD-падам рядом с CN3

| Площадка | Сигнал STM32L072        | Сигнал J-Link        |
| -------- | ----------------------- | -------------------- |
| GND      | Земля                   | GND                  |
| NRST     | NRST                    | RESET (необязателен) |
| VCC      | 3,3 В / опорное питание | VTref                |
| SWCLK    | PA14                    | SWCLK                |
| SWDIO    | PA13                    | SWDIO                |

> [!TIP]
> Клавиатуру можно питать от USB. В таком случае подключите её VCC к VTref J-Link только для измерения опорного напряжения 3,3 В. Либо подайте 3,3 В напрямую от программатора. Не используйте оба источника питания одновременно.

### Скрипт автоматического полного бэкапа

Создайте файл `backup_jlink.jlink`:

```text
r
halt
// 1. Полный дамп Flash: 128 КБ = Bank 1 + Bank 2
savebin hhkb_full_flash_128k.bin 0x08000000 0x00020000

// 2. Заводской Bank 1: 64 КБ
savebin hhkb_bank1_bootloader_64k.bin 0x08000000 0x00010000

// 3. Заводской Bank 2: 64 КБ
savebin hhkb_bank2_stock_firmware_64k.bin 0x08010000 0x00010000

// 4. Встроенный EEPROM: 6 КБ, калибровки Topre, серийный номер и флаги
savebin hhkb_eeprom_6k.bin 0x08080000 0x00001800

// 5. Option Bytes STM32L072: защита и параметры загрузки
savebin hhkb_option_bytes.bin 0x1FF80000 0x00000020

q
```

Запустите бэкап одной командой:

```bash
JLinkExe -device STM32L072RB -if SWD -speed 4000 -autoconnect 1 -CommanderScript backup_jlink.jlink
```

### Восстановление через J-Link

Для возврата Flash и EEPROM этой же клавиатуры создайте `restore_jlink.jlink`:

```text
r
halt
loadbin hhkb_full_flash_128k.bin 0x08000000
loadbin hhkb_eeprom_6k.bin 0x08080000
r
g
q
```

Этот сценарий восстанавливает Flash и EEPROM из полного бэкапа. Option Bytes он намеренно не перезаписывает: восстанавливайте их только при подтверждённой необходимости и из бэкапа той же платы.

## Карта памяти

| Область | Адрес                   | Назначение                                                   |
| ------- | ----------------------- | ------------------------------------------------------------ |
| Bank 1  | `0x08000000–0x0800FFFF` | Заводской PFU-обновитель; B4.16 в сохранённом бэкапе Classic |
| Bank 2  | `0x08010000–0x0801FFFF` | Заводская A4.29 или DMK                                      |
| EEPROM  | `0x08080000–0x080817FF` | Заводские данные и настройки DMK                             |

## Восстановление

Для обычного восстановления войдите в Bank 1 через SW6 и установите подходящий заводской `.hfb` через [официальный центр загрузки HHKB (Keymap Tool и обновления прошивки)](https://happyhackingkb.com/download/) или `hhkb_flasher.py`. Запущенный DMK штатная утилита не распознаёт.

DFU или SWD позволяют восстановить сохранённый Bank 2. Полное восстановление Flash, EEPROM или Option Bytes — операция для опытных пользователей: используйте бэкап только той же клавиатуры и не перезаписывайте оригинальные файлы.

## Recovery SW6

При `HHKB_SW6_REBOOT_TO_BANK1=1` запуск DMK с SW6 в ON инвалидирует Bank 2, стирает его первую 128-байтную страницу векторов и перезагружает MCU в Bank 1. В стёртой странице находятся начальный указатель стека и вектор сброса, поэтому Bank 1 больше не может передать выполнение в Bank 2. Это сохраняется после отключения питания: Bank 2 не загрузится, пока в него заново не будет записан полный совместимый образ через PFU-обновитель, DFU или SWD.

После этого перехода через Bank 1 можно установить последнюю подходящую заводскую прошивку со [страницы загрузок HHKB](https://happyhackingkb.com/download/) — штатным Keymap Tool либо `hhkb_flasher.py`. Выберите HFB для обычной Classic или Classic Type-S. В обычной работе SW6 должен быть OFF.
