# Конфигурация

## Определения сборки

- `HHKB_RAPID_TRIGGER` включает Rapid Trigger и его меню VIA.
- `HHKB_TYPE_S` выбирает Type-S модель HFB.
- `HHKB_ADC_16MHZ` выбирает HCLK/2 для АЦП вместо HCLK/4.
- `HHKB_ADC_OVERSAMPLING` задаёт исходное положение переключателя VIA для аппаратного усреднения ×4. Фактически ×4 работает только при 50–500 Гц; при 1000 Гц используется ×1. Настройка пользователя сохраняется в EEPROM.
- `HHKB_ADC_DMA` включает синхронизированную передачу каждого результата ADC1 через DMA1 Channel 1. Сканер по-прежнему запускает отдельное преобразование после импульса строки и ждёт его завершения. На проверенной плате при ×4 этот режим не ускорил сканирование.
- `HHKB_FACTORY_THRESHOLDS` загружает заводские пороги и поправки конкретной платы из EEPROM для классического режима.
- `HHKB_SCAN_DIAGNOSTICS` добавляет счётчики для измерений через SWD.

## Сканирование матрицы

Матрица Classic имеет 15 столбцов и 4 строки. DMK выбирает столбец мультиплексора, импульсом PC8 разряжает измерительный путь, переводит одну строку в LOW, ждёт установления аналогового сигнала, выполняет одно преобразование АЦП, отпускает строку и повторяет цикл для всех позиций. PC14 питает сенсорную часть, PC7 включает усилитель, PA1 — ADC1_IN1.

Таймерный сканер включён по умолчанию. VIA выбирает 50, 125, 250, 500 или 1000 Гц; пункт 1000 Гц использует целевой период 950 мкс. Сканер исполняется из SRAM, а TIM2 задаёт аналоговые задержки.

## Распиновка матрицы и периферии

- **Матрица:** 4 строки × 15 столбцов.
- **Строки:** `PB0`, `PB1`, `PB2`, `PB10` (маски `GPIOB` — `0x001`, `0x002`, `0x004`, `0x400`).
- **Столбцы:** два аналоговых мультиплексора 4051. `PC6` выбирает U1 для столбцов 0–7, `PB15` — U2 для столбцов 8–14; `PB12`, `PB13`, `PB14` — адресные линии канала.
- **Аналоговый тракт:** `PC14` питает сенсорную часть, `PC7` включает операционный усилитель, `PC8` разряжает накопительный конденсатор C57, `PA1` — вход ADC1 `ADC_IN1`.
- **DIP-переключатели:** `PA3`–`PA7` и `PC4`, активный низкий уровень.
- **LED:** `PA8` и `PA9`. VIA независимо назначает Off, Debug heartbeat, Caps Lock, Fn layer или System 2; по умолчанию PA8 показывает Caps Lock, PA9 — Fn layer.

## Заводские данные и калибровка

Заводские пороги классического режима загружаются из EEPROM самой клавиатуры при старте. Поэтому один образ DMK сохраняет индивидуальные пороги при установке на другую плату. Пользовательская калибровка хранит base и peak для каждой клавиши в отдельной записи EEPROM. Отключение пользовательской калибровки выбирает диапазон по умолчанию и не перезаписывает заводские таблицы.

## DIP-переключатели

SW1–SW5 читаются, но пока не имеют фиксированных действий DMK. SW6 по умолчанию запускает возврат в Bank 1. Fn + Space переключает две пары базового/Fn-слоя, Fn + Tab остаётся Caps Lock.
