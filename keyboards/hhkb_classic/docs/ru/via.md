# VIA

Загрузите `via.json` через вкладку Design в VIA. Пользовательский интерфейс находится в **HHKB Settings**: Scan Rate, Calibration, Rapid Trigger и LED. Rapid Trigger появляется только в сборке с `HHKB_RAPID_TRIGGER`.

Vial использует `vial.json` и умеет изменять раскладку. Пользовательские контролы VIA v3 в Vial не выводятся, поэтому аналоговые настройки, LED и частоту сканирования задавайте через VIA.

## Настройки

- Частота сканирования: 50, 125, 250, 500 или 1000 Гц.
- ADC oversampling ×4: переключатель в меню Scan Rate. При 50–500 Гц включает четыре аппаратных преобразования на клавишу с усреднением; при 1000 Гц всегда используется ×1. Выбор запоминается и снова действует после снижения частоты до 500 Гц или ниже.
- Tapping term: 50–500 мс с шагом 10 мс; по умолчанию 220 мс.
- Quick tap: 0–500 мс с шагом 10 мс; по умолчанию 150 мс; 0 выключает функцию.
- Точка срабатывания, классический гистерезис, RT press/release: 0,1–4,0 мм с шагом 0,1 мм.
- Верхняя мёртвая зона RT: 0,0–0,6 мм с шагом 0,1 мм.
- PA8 и PA9: Off, Debug heartbeat, Caps Lock, Fn layer или System 2.

Шкала миллиметров линейно отображает откалиброванный диапазон сигнала на условный ход 4 мм. Это шкала настройки, а не механическое измерение.

Start calibration сохраняет базовые значения отпущенных клавиш. Затем прожмите нужные клавиши до упора и используйте Finish and save. Меняются только позиции с валидным диапазоном сигнала.

Настройки и калибровка хранятся в EEPROM с `0x08081500`. Раскладки VIA используют другие зарезервированные слоты EEPROM.
