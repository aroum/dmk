# Отладка и HID Console

Прошивка DMK для HHKB Classic поддерживает вывод диагностических логов в реальном времени через стандартный интерфейс USB HID Console. Это позволяет отслеживать работу емкостной матрицы Topre, измерять реальные значения АЦП, контролировать частоту сканирования и анализировать команды конфигуратора.

По умолчанию весь вывод отладки **отключен**, чтобы не нагружать микроконтроллер и USB-шину.

---

## Активация отладки

### 1. Включение консоли в интерфейсе VIA
1. Откройте [веб-версию VIA](https://www.usevia.app/).
2. Перейдите в верхнюю вкладку **Settings** (иконка шестерёнки).
3. Включите пункт **Show HID Console tab**.
4. В верхней панели навигации появится новая вкладка **HID Console**.

### 2. Включение каналов логирования в клавиатуре
1. Перейдите на вкладку настройки клавиатуры (**Configure**).
2. Откройте меню **HHKB Settings** → подменю **Debug**.
3. Включите нужный канал:
   - **Topre Matrix Logging** — вывод событий срабатывания/отпускания клавиш с координатами `(col, row)`, сырым значением АЦП (`raw`), нормализованным значением (`norm` в диапазоне 0..1000 permille) и текущим состоянием нажатия.
   - **VIA Protocol Logging** — вывод отладочных сообщений протокола VIA/Vial при чтении и записи настроек.
   - **Rate Monitor Logging** — периодический вывод реальной частоты сканирования матрицы Topre и частоты USB-задачи (например: `[RATE] Matrix: 1000 Hz, USB: 500 Hz`).

> [!TIP]
> При необходимости логи можно экспортировать в файл или очистить прямо на вкладке **HID Console** в VIA с помощью кнопок в правом верхнем углу окна вывода.

## Нелинейная характеристика емкостного датчика Topre

Емкостной сенсор Topre представляет собой подвижную коническую пружину над контактными площадками печатной платы. Изменение ёмкости нелинейно зависит от физической глубины хода штока:

| Физический ход клавиши | Значение датчика (% / ‰) | Поведение и физика механизма |
|---|---|---|
| **0 мм** | **0%** (0 ‰) | Клавиша в покое (baseline), конус максимально удалён от платы. |
| **1 мм** | **15%** (150 ‰) | Начальное сжатие эластомерного купола; ёмкость нарастает медленно. |
| **2 мм** | **50%** (500 ‰) | Вершина тактильного сопротивления (tactile bump). |
| **3 мм** | **80%** (800 ‰) | Срыв купола, резкое приближение витков пружины к текстолиту. |
| **4 мм** | **99%** (990–1000 ‰) | Полное нажатие до упора (bottom out), максимальная ёмкость (peak). |

### Значения по умолчанию в DMK:
- **Точка срабатывания (Actuation point):** **75% хода** (750 ‰, около 2.8 мм). Клавиша гарантированно регистрирует нажатие сразу после преодоления тактильного барьера, что исключает случайные срабатывания при касании клавиш.
- **Гистерезис отпускания (Release hysteresis):** **0.4 мм** (100 ‰). Предотвращает повторные паразитные срабатывания и дребезг на границе срабатывания.
- **Rapid Trigger:** по умолчанию отключен, включается пользователем при необходимости через меню **HHKB Settings → Rapid Trigger**.
