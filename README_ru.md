# DMK Firmware (На русском)

Легковесная, современная и высокомодульная прошивка для клавиатур, разработанная для кроссплатформенной совместимости с микроконтроллерами.

**Документация:** [Сборка](docs/ru/build.md) • [Конфигурация](docs/ru/config.md) • [Коды клавиш](docs/ru/keycodes.md) • [Раскладка](docs/ru/keymap.md) • [Пины](docs/ru/pins.md) • [Vial](docs/ru/vial.md)

## Возможности

### Поддержка аппаратного обеспечения и платформ

- **Кроссплатформенность**: Единый код ядра для разных микроконтроллеров:
  - **Миландр** (K1986BE92FI)
  - **Raspberry Pi** (RP2040 / RP2350)
  - **Nordic Semiconductor** (nRF52840)
  - **Байкал** (BE-U1000)
- **Поддержка сплит-клавиатур**: Проводная связь между половинками (UART или Bit-Bang).
- **6KRO (6-Key Roll Over)**: Передача до 6 одновременно нажатых клавиш + модификаторы по USB HID.
- **Работа поверх FreeRTOS**: Использование FreeRTOS для сканирования матрицы и обработки событий через очереди.

### Расширенные функции раскладки и карты клавиш (Keymap)

| Функция                           | Код / Макрос              | Описание                                                                                   |
| :-------------------------------- | :------------------------ | :----------------------------------------------------------------------------------------- |
| **Вложенные слои**                | `K_TRNS`, `0..15`         | До 16 активных слоев, накладывающихся друг на друга с прозрачным пробросом нажатий         |
| **Временное переключение**        | `MO(layer)`, `L_0..L_15`  | Активирует слой, пока удерживается клавиша                                                 |
| **Фиксация слоя**                 | `TG(layer)`               | Переключает (включает/выключает) состояние слоя                                            |
| **Залипающие клавиши (One-Shot)** | `OS(K_LSFT)`, `OS(layer)` | Активирует модификатор или слой только для следующего одиночного нажатия                   |
| **Удержание-Тап (Hold-Tap)**      | `HT(hold, tap)`           | Ведет себя как одна клавиша при быстром тапе и как другая (модификатор/слой) при удержании |
| **Модифицированная клавиша**      | `MK(mod, key)`            | Отправляет код клавиши с заданной маской модификатора (например, `Shift + D`)              |
| **Физические аккорды**            | `my_chords[]`             | Выполняют кастомные функции при одновременном зажатии нескольких клавиш                    |
| **Многошаговые макросы**          | `M(index)`                | Последовательности нажатий, отпусканий и точных задержек в миллисекундах                   |
| **Синхронизация языка и слоя**    | `M(index)` + `TG(layer)`  | Макрос отсылает хоткей смены языка в ОС (`Shift+Alt`) и переключает слой на прошивке       |
| **Поддержка Vial / VIA GUI**      | `#define VIAL`            | Настройка раскладки, макросов и переназначение клавиш в реальном времени через Vial GUI    |

## Сравнение размера кодовой базы

DMK — не самая функциональная прошивка, и это намеренное решение. Проект не ставит целью полностью воспроизвести весь функционал QMK/ZMK/TMK/RMK/KMK, в которых из-за избытка редко используемых возможностей размер кодовой базы сильно разросся.

DMK сфокусирована на ограниченном наборе возможностей, которого достаточно для 99% пользователей. При этом благодаря простоте и прозрачности кода любые недостающие функции легко реализовать самостоятельно.

Благодаря такому подходу можно очень быстро и просто добавлять поддержку новых микроконтроллеров (главное требование — поддержка FreeRTOS). Например были добавлены Миландр и Байкал.

Ниже приведено сравнение размера кодовой базы DMK с другими прошивками. Измерение выполнено в строках исходного кода (SLOC) — учитываются только файлы `.c`, `.h`, `.cpp`, `.rs`. Документация, конфигурации, сторонние библиотеки и автоматически сгенерированные файлы исключены.

| Проект                                                 | Язык | SLOC   | Относительно DMK |
| :----------------------------------------------------- | :--- | :----- | :--------------- |
| **DMK** (~6.9K ядро + ~6.7K платформы)                 | C    | ~13.5K | 1×               |
| [TMK](https://github.com/tmk/tmk_keyboard) (tmk\_core) | C    | ~33K   | 2.4×             |
| [RMK](https://github.com/HaoboGu/rmk)                  | Rust | ~54K   | 4×               |
| [QMK / Vial-QMK](https://github.com/vial-kb/vial-qmk)  | C    | ~76K   | 5.6×             |

### Поддержка Bluetooth (BLE)

Полноценная поддержка BLE не планируется:

- **Минимальный размер кода**: BLE-стек и менеджмент питания увеличат объем кода в несколько раз. Главная цель DMK — простота и понятный код.
- **Проводное подключение не требует энергосбережения**: Для USB не нужно усложнять архитектуру спящими режимами.
- **Фокус на редких MCU**: DMK делается для микроконтроллеров без готовых клавиатурных экосистем (Миландр, Байкал). Для nRF52 с BLE уже есть ZMK и RMK.

Если понадобится беспроводное подключение, его проще реализовать выносом на отдельный внешним BLE-модуль по UART, не усложняя ядро прошивки.

## Система сборки

Сборка целевой прошивки осуществляется с помощью вспомогательного скрипта `./build_all.sh`.

### Использование

```bash
./build_all.sh [OPTIONS]
```

### Примеры команд сборки

- **Очистка и сборка Corne (RP2040)**:

  ```bash
  ./build_all.sh -b corne --mcu rp2040 -c
  ```

- **Очистка и сборка Kabarga (nRF52840)**:

  ```bash
  ./build_all.sh -b kabarga --mcu nrf52840 -c
  ```

- **Очистка и сборка Pncateho (nRF52840)**:

  ```bash
  ./build_all.sh -b pncateho --mcu nrf52840 -c
  ```
