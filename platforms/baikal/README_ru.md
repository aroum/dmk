# Платформа Baikal BE-U1000

Поддержка отечественного 32-битного RISC-V микроконтроллера **BE-U1000** от компании «Байкал Электроникс» в DMK Firmware.

## Особенности

- **Архитектура**: RISC-V RV32IMC на частоте до 100 МГц.
- **Память**: 256 КБ Flash (16 КБ выделено под бутлоадер, 240 КБ под прошивку DMK), 64 КБ RAM.
- **USB-контроллер**: Встроенный аппаратный USB 2.0 High Speed (480 Мбит/с) PHY на базе единого стека TinyUSB.
- **Частота опроса High Speed USB**: Поддерживается частота опроса до **8 кГц (интервал 125 мкс)** при сборке с флагом `-d HIGH_SPEED_USB`.
- **Загрузчик**: Поддержка UF2-загрузчика с режимом съемного накопителя:
  - Репозиторий: [baikal-uf2-bootloader](https://github.com/aroum/baikal-uf2-bootloader)
  - Имя тома в системе: `BAIKAL_LI`

## Прошивка и бутлоадер

1. **Вход в режим загрузчика**:
   - Двойное нажатие аппаратной кнопки Reset.
   - Либо зажатие кнопки Boot при нажатии Reset.
   - Либо вызов кейкода `K_BOOT` в раскладке клавиатуры (например, на слое Adjust).
2. **Прошивка**:
   - Плата определится как USB-накопитель `BAIKAL_LI`.
   - Скопируйте собранный `.uf2` файл в `/Volumes/BAIKAL_LI/` (или запустите `./build_all.sh ... -u`).
