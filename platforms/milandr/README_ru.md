# Платформа Миландр (K1986BE92FI / MDR32F9Q2I)

Поддержка отечественного 32-битного микроконтроллера ARM Cortex-M4 **К1986ВЕ92FI** (MDR32F9Q2I) производства ПКК «Миландр» в DMK Firmware.

## Загрузчики и прошивка

Платформа поддерживает два типа загрузчиков: **UF2 USB-накопитель** (по умолчанию при прошивке через USB) и **USB DFU**.

### 1. UF2-загрузчик (Рекомендуемый)
- **Репозиторий**: [K1986BE92FI-uf2-bootloader](https://github.com/aroum/K1986BE92FI-uf2-bootloader)
- **Имя тома в системе**: `K1986VE92FI`
- **Разметка памяти**: смещение 16 КБ (`0x08004000`), под приложение доступно 112 КБ Flash.
- **Вход в режим загрузчика**:
  - Двойное нажатие Reset (с интервалом до 500 мс).
  - Либо зажатие кнопки `PB6` при сбросе.
  - Либо программный вызов через кейкод `K_BOOT` в раскладке клавиатуры.
- **Прошивка**:
  1. Сборка с генерацией UF2 (включается автоматически при `-u` или `--uf2`):
     ```bash
     ./build_all.sh -b corne --mcu milandr -cu --uf2
     ```
  2. Перетащите файл `build/dmk_corne_milandr.uf2` на диск `K1986VE92FI` (или скрипт скопирует его автоматически с флагом `-u`).

### 2. DFU-загрузчик
- **Репозиторий**: [K1986BE92FI-dfu-bootloader](https://github.com/aroum/K1986BE92FI-dfu-bootloader)
- **Разметка памяти**: смещение 4 КБ (`0x08001000`), под приложение доступно 124 КБ Flash.
- **Прошивка через USB DFU**:
  1. Переведите плату в режим DFU, удерживая `PB6` при сбросе.
  2. Прошейте с флагом `--dfu`:
     ```bash
     ./build_all.sh -b corne --mcu milandr -cu --dfu
     ```
     Либо вручную через `dfu-util`:
     ```bash
     dfu-util -a 0 -d 1209:be92 -D build/dmk_<keyboard>_milandr.bin
     ```
